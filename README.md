# Data Privacy Services (DPS)

Data obfuscation and synthetic data generation for the enterprise — one Privacy Engine, three entry points
(API, database connectors, UI scanner), two outcomes (reversible obfuscation, synthetic data), measurable
privacy, and a hard rule that no LLM ever sees raw PII.

**Status:** design brief under review — see
[`docs/specs/2026-10-11-data-privacy-services-design.md`](docs/specs/2026-10-11-data-privacy-services-design.md)
(§12 lists the open decisions). Console mockups: [`docs/design/mockups/index.html`](docs/design/mockups/index.html).

Sibling services this repo follows for conventions and gateway access: Document AI Services
(`~/document_intelligence`), DES, DPC, the Wega orchestrator (Oracle), the Azure gateway.

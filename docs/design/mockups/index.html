Privacy Console — design mockups

Static HTML, no framework. These illustrate the "Vault" design direction and the three headline screens from the design brief §9. Use the floating control to toggle light/dark.

01 · Overview dashboard

Protection posture, the "raw PII sent to LLM: 0" promise, trends, layer cards.
02 · Playground (Layer 1)

Paste → detect → obfuscate / synthesize → reveal with key. The demo hero.
03 · Data sources & jobs (Layer 2)

Connector wizard, column classification heat-map, running job with partitions and evidence.
04 · UI scanner (Layer 3)

Crawl map, field inventory, and the parallel view: original screen beside the same screen filled with synthetic or obfuscated data. Never submitted.
Policies, Reports and Admin follow the same system and are mocked during their milestones.

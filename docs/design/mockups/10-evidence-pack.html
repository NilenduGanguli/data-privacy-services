7Regulatory note

CRM_MASKED is pseudonymised, and pseudonymised data is still personal data under GDPR Art. 4(5) and India's Digital Personal Data Protection Act 2023. Hold it under the same controls as CRM production. Whoever holds key k_01K7ZQ4M8V can re-identify every row.
The synthetic report is a measurement, not a claim. The fidelity and privacy figures in section 6 describe this run against a 200,000-row holdout. They do not state that CRM_SYNTH is anonymous. Treat it as confidential until your data protection officer decides otherwise; the synthesis seed can link rows back if someone also holds candidate originals.

DPS stores no customer values and no keys. This pack holds counts, hashes, column names, method names and key ids only. Its hash is written to the append-only audit log, so any later edit to the pack is detectable.
